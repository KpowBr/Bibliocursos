# 📚 BibliCursos

## Sobre o projeto

O BibliCursos é uma biblioteca digital criada por Kevin Luan com apoio de Inteligência Artificial Generativa, desenvolvida para facilitar o acesso à educação gratuita e de qualidade.

Seu objetivo é centralizar, organizar e divulgar cursos gratuitos oferecidos por instituições reconhecidas, funcionando como um catálogo inteligente que direciona o usuário para as páginas oficiais de cada instituição.

## Objetivos

- Democratizar o acesso ao conhecimento;
- Incentivar a educação continuada;
- Facilitar a descoberta de cursos gratuitos;
- Centralizar informações confiáveis;
- Promover capacitação profissional;
- Incentivar o desenvolvimento pessoal;
- Valorizar iniciativas de educação gratuita.

## Como funciona

1. O usuário acessa o BibliCursos;
2. Navega pelas categorias;
3. Encontra um curso;
4. Visualiza uma descrição;
5. É direcionado para o site oficial da instituição.

## Transparência

O BibliCursos:

- Não hospeda cursos;
- Não realiza matrículas;
- Não emite certificados;
- Não substitui as plataformas oficiais.

Sua função é exclusivamente organizar informações públicas e direcionar o usuário para os respectivos sites oficiais.
